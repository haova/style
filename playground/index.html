Customize

presetHaoVA({
  color: {
    primary: '#4ab9b2',
    surface: '#fff',   // anchor
    content: '#111',   // anchor
    palettes: {
      dark: { surface: '#0b1020' },
    },
  },
})

surface and content are anchors; light and dark follow from them (flip the scheme from the top bar). Anything you leave out is inherited, per color.fallback ('interpolate' or 'default'). Changing surface also moves primary; set it inside a palette to pin it.

Inter — the default family

Fraunces — the heading family

JetBrains Mono — the mono family

Customize

typography: {
  size: '1rem',                      // anchor
  family: ['Inter', 'sans-serif'],
  families: {
    heading: ['Fraunces', 'serif'],  // inherits family if omitted
    mono: ['JetBrains Mono', 'monospace'],
  },
}

size is the anchor; every type-* is a fixed factor of it. Each name in families becomes a font-* class, and heading falls back to family.

Customize

spacing: {
  base: '0.25rem',          // anchor
  gaps: {
    normal: { x: 2, y: 2 }, // multiples of base
    huge: 8,                // adds p-huge, m-huge, radius-huge
  },
}

Every size is a multiple of base. tight, normal and loose default to 1×, 2×, 4×. A gap takes a number, { x, y } or { t, r, b, l }.

Customize

line: {
  width: '1px',
  style: 'solid',           // 'dashed' | 'dotted'
  color: '$color.primary',  // reference; defaults to content
}

border-N multiplies width. A value starting with $ reads another option, so the line follows the palette.

05 · Multiple

Breakpoint

Padding steps up at every breakpoint.
1 column
tablet: 2
desktop: 3
wide: 4

Customize

breakpoint: {
  base: '40rem',               // anchor
  steps: { desktop: '70rem' }, // override a step or add one
}

Steps default to base × 1.25 per index: mobile, tablet, desktop, wide. Prefix any class with the step name, e.g. tablet:p-loose.

Escape hatch
