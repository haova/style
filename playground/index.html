Customize

presetHaoVA({
  color: {
    primary: '#4ab9b2',
    surface: '#fff',   // anchor
    content: '#111',   // anchor
    palettes: {
      dark: { surface: '#0b1020' },
    },
  },
})

surface and content are anchors; light and dark follow from them (flip the scheme from the top bar). Anything you leave out is inherited, per color.fallback ('interpolate' or 'default'). Changing surface also moves primary; set it inside a palette to pin it.

Customize

typography: {
  size: '1rem',                      // anchor
  family: ['Inter', 'sans-serif'],
  families: {
    heading: ['Fraunces', 'serif'],  // inherits family if omitted
    mono: ['JetBrains Mono', 'monospace'],
  },
}

size is the anchor; every type-* is a fixed factor of it. Each name in families becomes a font-* class, and heading falls back to family.

Customize

spacing: {
  base: '0.25rem',          // anchor
  gaps: {
    medium: { x: 6, y: 4 }, // change a step
    card: 12,               // adds p-card, m-card, w-card, radius-card
  },
}

Every size is a multiple of base. The six names double at each step: tiny 1×, small 2×, medium 4×, large 8×, huge 16×, giant 32×. A gap takes a number, { x, y } or { t, r, b, l }.

Customize

line: {
  width: '1px',             // anchor
  style: 'solid',           // 'dashed' | 'dotted'
  color: 'primary',         // a color name; defaults to content
  widths: { thick: 6 },     // adds border-thick, border-t-thick, ...
}

border is one width. The six names double at each step: tiny 1×, small 2×, medium 4×, large 8×, huge 16×, giant 32×. The color is a name, so the line follows the palette in light and dark.

05 · Multiple

Breakpoint

Padding steps up at every breakpoint.
1 column
tablet: 2
desktop: 3
wide: 4

Customize

breakpoint: {
  base: '40rem',               // anchor
  steps: { desktop: '70rem' }, // override a step or add one
}

Steps default to base × 1.25 per index: mobile, tablet, desktop, wide. Prefix any class with the step name, e.g. tablet:p-medium.
